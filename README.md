# 中醫藥庫進銷存

私人專案，管理中藥進貨、當天耗損、訂購與盤點。所有數量使用「瓶」；銷指當天耗損，不包含零售收款或克數換算。

## 目前完成

- GitHub 私人程式庫。
- 庫存核心計算與自動測試：期初、進貨、耗損、退貨、盤盈、盤虧、重複交易檢查。
- 已確認交易以沖銷更正，保留歷史記錄。
- 不依賴外部套件，可直接以 Node.js 執行。
- 已保存使用者提供的[原進貨入庫GAS及功能對照](gas/restock/README.md)，尚未連接或部署到線上GAS。
- 已依上傳Excel更新V2主檔650筆，加入[可重複執行的Excel匯入工具與欄位說明](docs/Excel匯入.md)。

目前是開發基礎，尚未提供正式網站、多人登入、持久化資料庫或Google Sheets自動同步。記憶體內的測試帳本不適用於正式記帳。

## 執行測試

安裝 Node.js 22 或更新版本後，在專案目錄執行：

```sh
node --test
```

## 後續介面

1. 首頁：缺貨、低庫存、尚未到貨。
2. 藥品：依廠牌、單複方與藥名搜尋。
3. 進貨：訂單核對、實際到貨瓶數。
4. 每日耗損：填瓶數、確認前顯示預計剩餘庫存。
5. 訂購：建議訂量、分批到貨與列印。
6. 盤點：帳面與實盤差異、調整原因。
7. 操作歷史：經手人、固定日期、原交易與更正關係。

## 正式上線前

現有Sheets V2已依11508藥局excel.xlsx整理650筆；30筆缺有效編號，250筆有來源疑點。原613筆版本已另行備份。Excel瓶數是歷史快照，需先完成核對、實盤與期初建帳。

程式與測試可存入GitHub；真實藥庫紀錄、帳密與金鑰不放入程式庫。部署後以資料庫作為唯一庫存依據，Sheets作為匯出報表。
