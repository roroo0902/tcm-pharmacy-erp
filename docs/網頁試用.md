# 藥庫網站使用範圍

[開啟網站](https://roroo0902.github.io/tcm-pharmacy-erp/)

每日耗損已改用 Google 雲端帳：選日期、經手人，填當日累計量，開啟 Google 預覽後確認差額。相同累計不重扣、增加只扣差額、減少須原因並加回庫存。留白不改，0 歸零。六個廠牌類別分頁共用雲端紀錄；操作細節見 [耗損 V3](../gas/loss/README.md)。

進貨、藥品建帳、本機交易紀錄、名冊與備份仍為此瀏覽器的試用帳。請先實盤建帳，再進貨；更正使用沖銷。它們不更新 Google 庫存。舊本機耗損歷史仍保留於本機備份，不會自動搬到雲端再扣一次。

網站上當日耗損以 Google 確認頁結果為準；入帳後重新讀取工作表。未送出輸入在重新整理或離開頁面後清除，切換廠牌或搜尋會保留。

「備份與還原」僅包含本機帳本，雲端耗損請另備份 Google 試算表。不同瀏覽器的本機帳本各自獨立。

GitHub Pages 使用 main 根目錄。index.html 為入口，web/ 為介面；不公開真實藥庫紀錄或憑證。
驗證使用 `node --test`，GAS 產生使用 `node scripts/build-loss-gas.mjs`。
