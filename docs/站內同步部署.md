# 站內核對與 Google Sheets 直接入帳

2026-10-29 已取得使用者確認，完成 Cloud 專案切換、Apps Script API 啟用、管理者白名單與 MYSELF API 執行檔第 18 版部署。GitHub 網址已登入並讀取六個庫存分頁，完成隔離測試品項的建檔、進貨與累計耗損驗證。另一台實體裝置尚未人工登入驗證。

## 操作流程

登入 Google → 填寫交易 → 在網站核對最新雲端預覽 → 確認入帳 → 原有 GAS 交易核心寫入並讀回。

建檔、進貨、單筆及批次訂貨、進貨沖銷、取消訂貨、每日累計耗損共用直接呼叫通道。訂貨只建立訂單，不增加庫存。耗損預覽會建立缺少的完整日期欄，確認前不扣庫。

庫存總覽停留前景時每 15 秒重新讀取，切回分頁或完成交易也會重新讀取。這是定時更新，不是即時推播。其他裝置須使用獲准帳號登入；關閉或休眠中的裝置恢復時再讀取。

六個分頁的同步讀取合併成一次 API 呼叫。OAuth token 僅存記憶體，重新整理或過期時重新登入。瀏覽器只保留草稿與待核對交易編號，不把本機帳當正式庫存。網路失敗不自動重送寫入。
