# Google Sheets 雲端查詢

來源為使用者指定的「藥品庫存表(查詢用)」。2026/10/27核對六個藥品分頁：科達單方／複方、天明單方／複方、富田單方／複方。統計每周開藥天數與休診日期不當成藥品頁。

GitHub Pages預設進入雲端查詢，直接從Google CSV匯出端點讀取各分頁A1:M5000，無登入憑證、無伺服器代理，庫存資料不提交到GitHub。這依賴來源現有的知道連結即可存取權限；不更動分享設定。若改為限制存取，需另設Google登入授權，不能繼續匿名讀取。

開啟查詢頁時同步，停留且頁面可見時每60秒同步，亦可手動更新。各分頁顯示最後成功讀取時間；失敗保留本次頁面記憶體中的舊快照並標示失敗，不將舊資料當成最新。離開頁面取消請求及計時器。讀取超時25秒。

## 欄位定義

- B：原編號；D：藥名；F：原表更新欄；G：未拆封瓶數；K/L：缺藥標記／缺藥率。
- 僅G為查詢瓶數；不將H其他廠牌／剩餘量或I一週量混入瓶數。
- 空白顯示未填，非數字保留文字並提示，不轉0。重複編號依來源列分開保留並標示。
- F的MM/dd文字照原樣顯示，不補造年份。最新同步時間不保證來源盤點日期新鮮。
- 在讀取前驗證表頭；來源欄位改動則拒絕解析，需重新核對。新增廠牌分頁需更新SOURCES設定；目前上限5000列。

這是Google Sheets→網頁的單向查詢同步。單機版進貨、耗損、名冊不回寫Google Sheets，原GAS也不由GitHub Pages執行，避免雙重入帳。
