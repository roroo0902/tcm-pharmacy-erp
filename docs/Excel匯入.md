## 匯入工具

```sh
python -m pip install -r requirements-import.txt
python scripts/extract_excel.py /path/to/workbook.xlsx --out data/excel-import.json
python -m unittest discover -s test -p "test_excel_import.py"
node --test
```

這個工具唯讀解析Excel，輸出預覽JSON，不會寫Google Sheets、不會開啟巨集、不會執行GAS，也不會自動建立正式庫存。JSON含私有來源資料，放在Git忽略的data目錄。

每頁依實際「編號／藥品名稱／未拆封」表頭定位，不能固定使用同一欄號。來源欄位有調整或找不到必要表頭時應中止核對；不是藥品頁的摘要頁不匯入主檔。

原始0無文字完整保存，僅來源參考值轉為0；空白不轉成0。日期誤填在編號欄時保留原值、將編號留空並警示。不直接推定缺編號、廠牌對應或不同規格的合併。

來源鍵以分頁與列號追溯，X開頭ID由來源鍵產生；它不是跨版本自動比對保證。若下次Excel插入或移動列，應先用已保存庫存ID與經核對的藥品主檔做對應，不得直接用新列號覆寫現有品項。
