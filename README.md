# 本草藥庫｜勇者的補給站

管理中藥進貨、當天耗損、訂購與盤點。所有數量使用「瓶」；銷指當天耗損，不包含零售收款或克數換算。

## 冒險藥庫介面

![冒險藥庫場景](web/assets/adventure-valley.jpg)

八個操作頁面採用深藍選單、金色邊框與草原城鎮場景，搭配史萊姆守護者及紅、藍藥水圖示。電腦與手機共用同一網址；手機可橫向滑動選單與資料表，並保留原有排序、廠牌選擇、登錄及備份功能。

場景為生成式插畫；史萊姆、藥水與選單圖示為本專案 SVG。主題樣式集中於  `web/quest-theme.css`，各頁冒險文案位於 `web/quest-theme.mjs`。

## 執行測試

安裝 Node.js 22 或更新版本後，在專案目錄執行：

```sh
node --test
```

## 後續介面

1. 首頁：缺貨、低庫存、尚未到貨。
2. 藥品：依廠牌、單複方與藥名搜尋。
3. 進貨：訂單核對、實際到貨瓶數。
4. 每日耗損：填瓶數、確認前顯示預計剩餘庫存。
5. 訂購：建議訂量、分批到貨與列印。
6. 盤點：帳面與實盤差異、調整原因。
7. 操作歷史：經手人、固定日期、原交易與更正關係。

## 訂貨V2

新增廠商訂貨頁（科達、天明、富田，各分單方與複方），分開顯示原表訂量、期間耗損、新建議量及人工確認量。訂貨草稿本機保存；Google 寫入部署仍需完成帳號授權。修正版已儲存指定 GAS 專案，詳見 [訂貨V2說明](gas/orders/README.md)。


進貨登錄支援依六個來源工作表切換、列出所有品項、按編號／進貨數量／日期排序及新增品項。新增廠牌類別由分頁帶入。確認前核對期初瓶數，整批原子寫入既有本機帳本，可由交易紀錄沖銷、完整備份還原；不寫回 Google Sheets。未確認的輸入僅保留於目前進貨頁，重新整理或離開頁面會清除。
